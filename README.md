# 🌐 Portfólio & Currículo Web Semântico

Projeto desenvolvido como parte da atividade prática de **Desenvolvimento Web**, focando na construção de uma página de portfólio pessoal e currículo utilizando exclusivamente **HTML5 puro e semântico**.

---

## 📌 Sobre o Projeto

O objetivo desta atividade é demonstrar o domínio da estrutura semântica do HTML5, organizando dados pessoais, histórico de projetos, habilidades técnicas e um formulário de contato estruturado, garantindo acessibilidade, organização e boas práticas de navegação interna.

---

## 🚀 Funcionalidades e Seções

- **Cabeçalho & Navegação**: Título principal e menu com links de navegação interna (âncoras `#id`) para rápido acesso às seções.
- **Sobre Mim**: Apresentação pessoal, foto de perfil e lista de habilidades técnicas.
- **Meus Projetos**: Tabela organizada contendo o nome dos projetos, linguagens/tecnologias utilizadas, status atual de desenvolvimento e hiperlinks para os repositórios.
- **Formulário de Contato**: Formulário agrupado via `<fieldset>` e `<legend>`, contendo campos estruturados para nome, e-mail, seleção de assunto e caixa de mensagem com botões de envio.
- **Rodapé (`<footer>`)**: Informações de direitos autorais com caracteres especiais (`&copy;`) e dados de contato com links diretos (`mailto:` e telefone).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica do conteúdo (`<header>`, `<nav>`, `<main>`, `<section>`, `<table>`, `<fieldset>`, `<footer>`).
